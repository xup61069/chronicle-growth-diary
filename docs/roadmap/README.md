# Chronicle Roadmap

本目錄保存跨 sprint 的產品方向與工程規劃；它取代把所有已完成工作和歷史對話堆入 `todo.md` 的做法。`todo.md` 僅保留目前 sprint 的可執行事項與外部阻礙。

| 文件 | 用途 |
| --- | --- |
| [`CURRENT_SPRINT.md`](./CURRENT_SPRINT.md) | 目前儲存庫治理 sprint 的交付範圍與完成定義。 |
| [`FEATURES.md`](./FEATURES.md) | 年度回顧、語音日記、數據儀表板、印刷 PDF、家庭互動的分階段產品藍圖。 |

公開版本摘要請使用 [GitHub Releases](https://github.com/xup61069/chronicle-growth-diary/releases)；需要社群回饋、架構取捨或長篇提案時，請使用 [GitHub Discussions](https://github.com/xup61069/chronicle-growth-diary/discussions)。
