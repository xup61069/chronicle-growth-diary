# 文件入口

本目錄以**文件用途**而非提交時間組織。新貢獻者先讀交接、架構、測試與安全文件；功能規劃只在 roadmap 維護，驗證細節只在 validation 維護，避免把同一件事重複寫進 README、TODO 與 PR。

| 目的 | 文件 | 何時閱讀 |
| --- | --- | --- |
| 交接與已知限制 | [AI_HANDOFF.md](./AI_HANDOFF.md) | 每次 AI／維護者接手前。 |
| 系統架構與資料流 | [ARCHITECTURE.md](./ARCHITECTURE.md) | 修改路由、資料庫或儲存前。 |
| 測試放置與驗證 | [TESTING.md](./TESTING.md) | 新增或移動測試前。 |
| 本機開發與部署 | [LOCAL_DEVELOPMENT.md](./LOCAL_DEVELOPMENT.md) | 建置、資料庫或本機服務操作前。 |
| 安全與隱私 | [../SECURITY.md](../SECURITY.md) | 認證、分享、AI、媒體或兒童資料變更前。 |
| 視覺系統 | [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) | 公開或工作台介面變更前。 |
| 目前工程焦點 | [roadmap/CURRENT_SPRINT.md](./roadmap/CURRENT_SPRINT.md) | 排定本輪可交付工作時。 |
| 功能狀態與後續方向 | [roadmap/FEATURES.md](./roadmap/FEATURES.md) | 評估新功能範圍時。 |
| 驗證證據 | [validation/](./validation/) 與 [VALIDATION_LOG.md](./VALIDATION_LOG.md) | 需要可重現的視覺或品質基準時。 |

研究性或一次性參考文件，例如 [MEDIA_ARCHIVE.md](./MEDIA_ARCHIVE.md)、[SOCIAL_IMPORT_RESEARCH.md](./SOCIAL_IMPORT_RESEARCH.md) 與 [SELF_HOSTING.md](./SELF_HOSTING.md)，只在相關功能規劃時閱讀，不作為目前 sprint 的重複任務清單。
